# IsometricProjection

Minecraft 1.21.1 / NeoForge 21.1.265 客户端等轴正交相机原型。

每次进入世界、加载画面关闭后，在本地聊天栏显示一次简易玩法说明，按当前实际绑定的按键显示。
死亡重生和切换维度不会重复提示；退出再进入会重新提示。
等轴视角的右下角、快捷栏上方显示 I / G / V 对应功能的实时状态，按实际绑定的按键显示。
视错觉连接开启时，透视状态显示为“关闭（连接模式）”；F1 隐藏 HUD 时一起隐藏。

## 操作

| 按键 | 功能 |
| --- | --- |
| I | 开关等轴视角 |
| [ / ] | 每次平滑旋转 90 度，过渡约 0.25 秒 |
| = / - | 放大 / 缩小 |
| WASD | 沿等轴画面上、左、下、右方向水平移动 |
| 空格（原跳跃键） | 原版跳跃 |
| V | 开关玩家附近的局部透视 |
| G | 开关视错觉连接（单人世界，自动关闭透视） |
| 鼠标左键 / 右键 | 攻击 / 交互鼠标指向的可触及实体；方块操作沿用原版 |

可在游戏按键设置中修改。初始可视高度为 24 格，范围为 8–64 格。
固定俯角 35.26439 度、初始方位角 45 度，画面以玩家眼部为中心跟随。
逻辑相机留在玩家眼部，正交矩阵提供等效 32 格后移，避免影响声音、阴影和环境检测。
关闭后恢复开启前的第一/第三人称设置，离开世界后关闭模式。

等轴模式使用自由系统鼠标指针，鼠标不再拖动视角；上一版触及十字光标已移除。
WASD 按当前相机方向移动，不受玩家朝向影响。鼠标选取通过正交射线判定最近的方块面或实体。
玩家朝向由 WASD 移动方向决定，所有方向均转身后以前进姿势移动，斜向按键朝向合成方向；
松开按键后保持最后朝向。鼠标选取不会改变玩家身体、头部或俯仰朝向。
攻击、交互与放置继续使用原版处理，只允许在实际触及范围内操作，
并检查玩家至目标的障碍，不允许隔墙攻击。看得到的远处目标不会因此变得可交互。

跳跃及自动跳跃恢复原版逻辑和玩家设置，空格自动行走已删除。
旋转过程中 WASD 和鼠标射线跟随当前画面角度；连续按旋转键会衔接到新目标，
跨越 360 度时按原方向继续旋转，不会反向绕一大圈。
普通模式恢复原版鼠标捕获和移动。

局部透视默认随等轴模式开启，仅隐藏同时满足以下条件的方块：
方块位于玩家眼睛所在方块层或更高、位于头部朝向相机的前景深度范围内，
且方块中心投影落在玩家头部周围半径 4 格（投影平面世界单位）的圆形开口内。
开口沿相机视线向前延伸，随等轴相机旋转调整，而非移除玩家四周整圈屋顶。
保留头部层以下的方块、后方与开口外的建筑；按 V 关闭后可正常观察、选取屋顶。
玻璃、门等也按同一遮挡条件隐藏，不再单独保留；隐藏部分会被鼠标画面射线跳过。
鼠标的画面射线会跳过隐藏方块，选取室内可见目标；碰撞、玩家至目标的障碍检查、
触及距离和服务器方块数据保持原版逻辑，不允许穿墙走动或隔墙交互。
这是一种整方块局部隐藏效果，并非半透明材质；按方块中心投影判断开口边界。
玩家跨入新方块、眼睛高度变化、相机旋转或切换模式时重建相关渲染区块，边缘可能有短暂刷新延迟。

## 视错觉连接原型

单人世界中先按 I 开启等轴视角，再按 G 开启视错觉连接。透视自动关闭，期间 V 不会重新开启透视；
关闭连接或退出等轴模式后恢复此前的透视设置。
玩家在完整方块顶面步行接近边缘时，检测画面上与该边缘相接、但实际位置不同的完整方块顶面。
找到无遮挡、有落脚点及头部空间的连接后，由内置服务器执行传送，并在客户端预测落点。
主要传送偏移沿相机视线，因此场景的屏幕位置基本保持不变；保留水平速度和朝向，减少停顿。
在实际物理位移应用前检测整段移动，支持疾跑和连续连接；保留本次跨边缘后剩余的移动距离。
成功跨越不设置全局冷却，仅对同一连接的非主动折返做短暂保护，主动反向移动可正常返回。
等待服务器确认时暂时稳住预测落点，确认后恢复动量，避免惯性在确认前把玩家带下平台。
相机旋转过程中暂停连接检测，旋转稳定后按新角度重新判断。

首版限制：仅完整立方体碰撞方块，搜索上下各 16 格，投影对齐误差不超过约 0.015 格；
不支持半砖、楼梯、骑乘、飞行或跳跃过程中触发；透视必须关闭。
实体及落点碰撞、世界边界、加载状态均需通过检查；正常相邻的路面优先按原版行走。
多人服务器需要后续服务端支持，目前会提示不支持。

搭建示例：默认 45 度视角下，把 A 放在 `(0, 63, 0)`，把 B 放在 `(4, 66, -3)`。
B 的顶面投影与 A 的东侧顶面边缘接上，但实际不相连；站在 A 上朝东边缘走可触发连接。
可将 A 扩为小平台方便起步；平台东侧 `(1, 63, 0)` 应留空，且两端上方不要有遮挡。

## 构建

使用 JDK 21，运行 `gradlew.bat build`，产物位于 `build/libs/`。
开发客户端：`gradlew.bat runClient`。模组只需安装在客户端。
`build` 同时执行 `verifyControls`，检查四方向移动换算与不同缩放、宽高比下的鼠标射线投影。
